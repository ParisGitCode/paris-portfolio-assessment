My p5.js sketch created a dynamic grid of rectangles that rotate in different directions across the canvas. It divides the screen into 19 rows and columns, and then calculates each cell’s size and position with padding. Each cell displays a static rectangle and a semi-transparent rotating overlay, creating a layered animation effect. It repeats this.
Instead of manually repeating pieces of data, a for loop is used.
