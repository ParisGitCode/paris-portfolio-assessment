For my project, I wanted to create a flower with a face in the center to encorporate the emoji concept. This flower can change its petal color and facial expression every time I clicked. I started by declaring a variable called petals, which I thought was a fitting name to use throughout the sketch. I also created an array called mouthOptions to store different mouth expressions for the face, and a variable currentMouth to keep track of which one was currently showing, which I didn't use much because I wasn't too sure how to.

In the setup() function, I initialized the canvas at 600×400 pixels and set the starting color of the petals to red using color(255, 0, 0). I aligned the text to the center and set the text size to 40 so it could be big enough to see, which would be used for the facial features later on.

In the draw() function, I used translate(width / 2, height / 2) to center everything on the canvas, I divided the height and width by 2. I manually placed six petals around the center using ellipse(), two on the sides, two above, and two below. I struggled with positioning at first, so I relied on trial and error rather than math to get the layout right. I considered using a loop, but I wasn’t sure how to structure it, so I placed each petal individually. I think I could've pushed myself to use a loop instead but I kept running into errors when I tried and ultimately gave up.

For the center of the flower, I made it white so the face would be clearly visible. I originally used blue but this made the text harder to read. Then I added the face using text: "O O" for the eyes and a mouth from the mouthOptions array. I positioned the eyes slightly above the center and the mouth slightly below.

Finally, I created a mousePressed() function that changes the petal color to a random hue and cycles through the mouth expressions. I initially ran into issues with color changes because I tried using an array like (0, 0, 255) instead of the color() function. Overall for my first project I’m happy with how it turned out. The most time-consuming part was definitely positioning the petals, but I learned a lot about how ellipse() and translate() work so it was a positive overall.
